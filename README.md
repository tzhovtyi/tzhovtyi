### What I do

For six years I've been building production systems in TypeScript. Most recently I'm the technical owner of a cross-border logistics ERP that runs daily operations for 124 carrier and broker offices across China and Russia. Nearly all of my work lives in private repos, so here's the short version of what's in them.

**Logistics ERP & integration platform** · senior full-stack engineer

- ~20,000 compliance-critical documents a day exchanged with customs, carriers and brokers through BullMQ workers with idempotent jobs and human escalation on retry exhaustion.
- p99 API latency cut from ~1.3s to under 400ms using tiered PostgreSQL materialized views refreshed on per-dataset freshness schedules, plus EXPLAIN-driven composite and partial indexes.
- Built the observability stack (Grafana, Loki, Prometheus) and a Docker-based CI/CD pipeline on self-hosted GitHub Actions runners.
- Frontend bundle down ~40%, LCP from ~3.2s to ~0.9s.

**E-commerce rescue** · lead frontend

- Took over an abandoned, non-functional prototype and shipped it to production in 16 weeks: 25K monthly users, a 12K-SKU catalog, 95+ Lighthouse scores and mobile LCP under 0.8s.

**Government workstation provisioning** · full-stack

- A browser UI that drives a local agent over WebSockets, with in-browser detection of GOST cryptography support (CryptoPro, ViPNet) and graceful fallback across 30+ browser/OS combinations.
